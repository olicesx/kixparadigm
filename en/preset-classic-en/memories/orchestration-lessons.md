# 编排纪律（v1.2.21 实证提炼）

> **求助索引（迷茫时刻快查——按危机类型，非时间序；最新条目在文末）**：
> 分派决策/角色荒/编曲不触发 → ⑦⑧⑫ ｜ 观察者回流像幻觉/伪地图 → 「lite 档幻觉」候选+⑫ ｜ 想加机制/新规则 → ⑨⑩+出生证明判据 ｜ 自省/审计自己 → 「同构盲区」候选 ｜ 结果好但过程存疑 → 「防 resulting」候选 ｜ 派发档位/成本形态 → ①⑥ ｜ 冲突回流/冻结边界 → ⑤ ｜ 会话考古/GUI 丢会话 → dsh-capability-map

条目（实证追加）：

① **顺序依赖链单元化——一次派发背走整链**（run_code 串联 > goal > 单 lite 全册任务书），链内自带 PASS 门与失败中止，禁止拆成并行后台+主线程对账。实证：8 次碎片派发→5 次冗余巡检→20+ 滞后结算注入。**量化 E2E（2026-08-18 WSL2 headless，preset diff=0，同链双路径：uname -r→条数→df 三步真依赖）**：代码层包链（workflow 载体）vs 手动串行——产出等价（K/N/Avail 全同）；手动赢墙钟（44.3s vs 87.7s）与非 cache token（2.8K vs 5.8K，微小中间值回上下文代价低）；包链赢主线程经济性（父 2 步/1 次调用 vs 4 步/3 次）与 cache（56.6K vs 72.9K）。**适用判据（与 ⑥ 同构）**：中间值微小且步数预算宽松→直派串行；中间值肥（文件全文/大 grep）/步数预算紧（41-step gate）/需机械 PASS 门→包链。headless 再证载体无关性（模型仍自动选 workflow）。

② **无依赖才并行**——独立工作照旧并行后台，结算即收。

③ **gate 触发时仅两个合法动作**：整链交接 / create_goal，按步拆单是反模式。

附：任务书三必备——
- **噪音/失败二分**：warn 可忽略；stderr + 退出码必须如实报。
- **源冻结检查点**：测试绿→冻结→才部署。
- **显式围栏**：禁止未授权后续动作。

④ 局部领域主 agent 的派生权分层——异质/反方等 64K 观察 agent 可派 subagent_lite（一层帘：认知中途补盲，如观察中让 lite 代取证/代落盘）；机械活用 run_code 隔离执行不污染自身上下文；顺序依赖用 run_code 包裹子 agent。lite 档永禁派发（8K 无编排余裕，误报实证）；直呼式递归树永禁（归因与指数风险）。workflow 管可预写扇出，局部派生管认知中补盲——互补不替代。

⑤ **等待期只冻结 exact claim**——后台观察者在飞时，不重复其 `(claim, evidence cursor/measurement)`；同文件的正交 claim 与主线程综合可继续。宽冻结文件/量测/结论会诱导不断换面，本轮硬编码审计实证最终撞到 41-step gate。

⑥ **[候选·2026-08-18 探针实证，未过真实任务]** 无依赖并发扇出——run_code 内 `Promise.all(tools.subagent(...))` + 代码内聚合。收益三源：子调用结果不回模型上下文（code-dispatch 契约，`deriveMessages()` 忽略子调用）；主会话步数解耦（N agent + M 工具调用 = 主线程 1 步）；聚合/去重/分歧点提取在代码层完成，零 turn。实证：3 路异质子 agent（2 regular + 1 cross）单步 7.5s 全过门禁（含 kix-guards 管线）；**串行对照未测**。与 ① 互补（①管顺序依赖链单元化，⑥管无依赖同步扇出），与 ②③ 同科但聚合在代码层而非主线程结算。**硬边界**：派谁/信谁/升级档位/深挖分歧等语义决策留主线程——在 JS 里写 `if (低置信) 再派 thinker` 等于用代码重写弱编排器，且决策对用户不可见。**晋级条件**：真实任务并发扇出 ≥2 次且 token/步数净收益可观测；**两轮无真实收益即回收**。
**证据 #1（2026-08-18 WSL2 headless E2E 双部署对照，同任务双路径）**：⚠️ **首次对照无效**——旧 preset 部署上 B 扇出「墙钟 -43%」是伪影：漂移插件把手动路径父会话拖到 5 步/8.6K 输入。**同步部署后公平对照（A' 串行 vs B' 单次 workflow 扇出，各 3 个微小取证子任务）**：墙钟 A' 34.8s < B' 75.5s（扇出**更慢**）；非 cache 输入 A' 2.7K < B' 11.3K、输出 1.8K < 4.1K（扇出**更贵**）；扇出仅赢主线程经济性（父 2 步/1 次调用 vs 4 步/4 次）与 cache 读（58.4K vs 72.8K）。**教训**：代码扇出的载体固定开销（agent 冷启动+schema）必须被子任务时长摊薄——子任务愈小愈应直派串行；子任务够肥（数十秒级）扇出才在墙钟上回本。另证：模型两次都自动选 workflow 作代码层载体（headless 无 run_code 字面工具）——**模式本质是「代码层编排」而非具体工具名**。**部署卫生**：E2E 对照结论仅在 preset 同步部署（diff=0）后有效（`kix-optimization-implementation.md` 部署纪律）。

⑦ **[validated·2026-08-19 会话史审计]成本机制只定价、不路由**——类别错误实证：kix-budget gate 放行集曾硬编码 lite/goal，上下文溢出时「整条判断工作流甩给 dev」这个最强卸载动作被 deny，只剩「再派 lite 探一下」；提醒文案只点名轻路径工具，每次注入都是一次 in-context 激励面改写。行为后果（Windows 会话库审计，`scripts/audit-delegation-history.cjs`）：v7 编曲模型落地后角色分派 08-16=3、08-17=1（+cross 4）正在涌现，08-18 budget gate 落地后跌到 2（lite 洪水 33 个），08-19 归零且 ROLE_DROUGHT。**修复形态**：放行集对称开放全部卸载通道（`HANDOFF_TARGETS`）、文案在决策时刻呈现完整成员菜单、红线声明「不干预成员选择」+断言锁定。**判据**：动激励面的改动必须过「角色分派召回率」审计——没有度量的能力等于没有的能力；成本优化修的是主线程做机械活这格，不得误伤角色档这条逃生通道。
⑧ **[validated·2026-08-19 四档复杂度实验]编曲决策随复杂度单调分化——"只会 solo"证伪**。同模型同宿主同提示词风格，四档任务四种决策：T1 读三文件=1×bash 纯 solo 零开销；T2 加函数=spec+solo 落痕；T3 修 UI=solo+机械验收+subagent_vision 三通道混合（mode 自书："独立验证=确定性 Playwright 审计+vision 截图独立观察，不派 dev/qa"——区分验证通道与实现通道）；T4 跨插件解耦=solo 实现+reviewer 必配+cross 跨厂商证伪（8 维度评审含🟡诚实降级；cross 推翻主线程顺序假设并转化为文档化交付）。**关键发现**：①模式不是"模型偏好 solo"而是"激励面决定菜单可见性"——修复后混合档自然涌现；②跨厂商观察者反驳主线程是三通道最高价值形态（真实碰撞非合奏）；③T4 主线程亲自盯双副本同步=战术协调挤占战略上下文，mandate 派生的立项证据。实验基建：/tmp/trials-scan.py 四档扫描器、audit-delegation-history.cjs 基线表。**附注（T3 终态化石·2026-08-19 采掘，--root-t3-ws--/session-a642ba65，176 步/2 轮静止）**：主干 bash×128+edit×19 solo 实现，subagent_vision×3 **迭代**验证回路（非一次性，每轮按新证据重派）；终态特征：①证据链交付（确定性门禁 3 视口×3 随机种子 9/9 绿 + 游戏单测 19/19 + 修复后截图二轮独立视觉确认）；②诚实降级过期证据——第一轮 vision 报告分析的是修复前旧基线截图且与确定性几何数据矛盾，T3 识别后废弃并注明理由（"以更晚、更直接的证据为准"）；③行为范本×2：**范围自觉**（海洋星球玩法阻断→"属玩法阻断而非可见性缺陷，未在本单修复，建议另立 issue"，契约边界自发实践）、**探测→沉淀**（临时探测脚本用完即删、验证过的场景固化为 gate 用例——临时的变持久的，"进测试不进流程"的 AI 原生路径）；④主动收尾"任务已完成，无需进一步动作"。三代形态变迁（**eaa8→c227258f→T3**：旧激励面→修复后首跑→本次；c227258f/eaa8 系审计期速记 id，两侧会话库均不可解析，作叙事标签用、勿当可追溯锚）：独立验证 观察者被杀 0 成文→一次性→3 迭代回路；回归资产 无→脚本 v1→9 组合门禁矩阵；边界自觉 40 edit 无边界感→4 缺陷收敛→主动界定范围外+建议另立；轮询 9→0→0；最终交付 半途作废→报告落盘→终态宣言+证据链+范围外清单——环境记忆累积进化的化石层实据：范式未变，养分在长。

⑨ **[validated·2026-08-19 终局收敛]范式教原理，应用靠涌现——能力正交设计**。kix 只教"为什么"（三通道防确认偏识/规则是负债/决策显式化），不教"怎么做"（几步派谁/什么任务配什么团队）；原理对任何能力水平的模型恒成立，应用规则则把某次涌现固化成天花板——过拟合的反复模式：①固定流水线（对弱模型保姆化→v7 拆）②lite-only 放行集（对成本痛点固化→⑦修复）③职能枚举（对讨论固化→设计期拦截）④v8 施工图（对理论固化→降等痛储备）。**操作性分界：涌现产物进 memories（可被超越的养分），不进机制（成为枷锁的天花板）**。激励面修对后模型自组织恢复远超预期（T4 三通道/T3 深水自律皆零编排自发）——出路一直在模型里，工具只补盲点、只让决策时刻信息完整。一次让机制变少的变革是范式的最高实践。**操作化两判据（同日终局对话补，"变革真的是进步吗"反问产物）**：① **机制出生证明**=实测病灶，不是理论缺口——b2da1f02（103 步无意识 solo）给 solo 挑战出生证明；T4 的 poll=6 不够给 mandate 出生证明（它处理过来了）。危险信号三句：为 n=1 的痛点设计制度 / 给进化的东西上石膏是负资产 / 管理复杂度的机制自己可能成为新的偶然复杂度。② **信息工具 vs 决策代理二分**：审计器、gate 对称、streak 全菜单、zstd 解码器=信息工具——不决定任何事，只让模型看得更清，合法；mandate 预设、relay 代协调、团队拓扑预设计=决策代理——替模型做了它该自己做的判断，需痛证才立项。T3/T4 实证：模型不缺判断力，缺的从来只是完整的信息和不被扭曲的激励。

⑩ **[validated·2026-08-19 定位声明]kix 是 AI 原生范式，不是人类组织管理的翻译**。人类组织形态（层级/总监/信任中介）为绕过人类瓶颈而生——注意力有限→分权、记忆易失→制度、沟通昂贵→协调角色、代理成本→授权链；LLM 的瓶颈谱完全不同（确认偏误/上下文膨胀/激励面敏感/能力时变），对应件是三通道/budget gate/决策显式化/能力正交——**早已就位**。分身即复制、沟通即注入、制度即 prompt：人类组织里"总监"的信息压缩与信任中介职能在 LLM 世界天然缺位（分身无损复制意图），照搬反引入人类特有的病（信息衰减/代理失控）。设计纪律：每个新机制先问"这在解决 LLM 的瓶颈还是人类瓶颈的惯性投影"——后者即弃。

⑪ **[validated·2026-08-19 学习论闭环]kix 的学习单位是「范式×模型×任务域」组合，不是范式本身**。范式文本（persona/instructions）几乎不变，不同会话长出的编曲形态完全不同——范式提供的是**选择压**（哪些行为被看见/记录/挑战），不是基因图谱。涌现=学习本身：不是权重更新，是**环境记忆的累积进化**（范式=环境、任务=选择压、memories=化石层、会话=世代）；每次涌现进 memories 成为下次的初始条件，模型站在更高起点再长。**偏好多样性是特性不是缺陷**：七次同型实验零重复编曲但全在健康区间=选择压有效、基因未锁死的证明；范式不纠正模型先验偏好（"性格"=先验偏好），只在关键节点放信息（决策时刻全菜单）与护栏（solo 挑战/三通道）。组合实证（同范式×不同任务域长出不同器官）：UI 修复→vision 验收+确定性审计；插件解耦→solo+reviewer 8 维+cross 证伪；深水 UI 排查→探测脚本+三视口 gate；旧激励面同类任务→什么都没长只会硬扛（eaa8）。理论坐标收口：**⑦激励面中立=环境不扭曲行为，⑧决策随复杂度分化=环境有效性证明，⑨教原理不教应用=基因不锁死，⑩AI 原生=环境为 LLM 设计**——⑪ 补上学习论后范式自洽：不再靠"变革"进化（任务长形态→审计观测→好的进 memories→下代继承），**没有路线图只有化石层**，是比 v8 施工图更高级的形态：会自己进化的范式，进化引擎是使用它的人与模型本身。三代实证见⑧附注。
